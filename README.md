# لوحة أداء المتجر والإعلانات

يحتوي المشروع على صفحة خدمة عربية عامة ومدخل مستقل لأداة المالك. `app.py` هو مدخل Streamlit العام، ويشغّل صفحة الخدمة `service_app.py`. محلل الملفات محفوظ محليًا باسم `owner_app.py` ولا ينبغي جعله مدخلًا عامًا.

## صفحة الخدمة المدفوعة

تعرض الصفحة خدمة التقارير المدفوعة فقط، مع رابط واتساب مباشر إلى الرقم `+966559665030` ورسالة استفسار جاهزة. لا تحتوي على رفع ملفات أو تحليلات مجانية. النطاق السعري **$50–$150 للتقرير أو الاشتراك** بحسب نطاق العمل، ويُتفق على السعر النهائي قبل البدء. التواصل والاتفاق والدفع وإعداد التقرير وتسليمه تتم يدويًا خارج الصفحة؛ لا يوجد دفع مدمج أو تسليم آلي.

للمعاينة المحلية المباشرة استخدم `streamlit run service_app.py`؛ وهي نفس صفحة الخدمة التي يشغّلها المدخل العام `app.py`.

## محلل المالك

يظل `owner_app.py` أداة تحليل ملفات محلية للمالك. لا تعرضه للعامة دون إضافة مصادقة وعزل مناسبين.

- إجمالي الإنفاق والإيراد والطلبات ضمن الفترة المختارة.
- **ROAS** = الإيراد ÷ الإنفاق الإعلاني، وليس عائداً صافياً أو ربحاً.
- **CPA** = الإنفاق ÷ الطلبات، و**CPC** = الإنفاق ÷ النقرات.
- **CTR** = النقرات ÷ مرات الظهور، و**معدل التحويل** = الطلبات ÷ النقرات.
- **AOV** = الإيراد ÷ الطلبات.
- مرشح تاريخي، مقارنة أعلى 20 فئة حسب عمود يختاره المستخدم، واتجاه الإيراد اليومي عند توفر التاريخ والإيراد.

يعرض المحلل المؤشر على أنه «غير متاح» عندما لا تتوفر الأعمدة اللازمة أو يكون المقام صفراً. يكتشف أسماء أعمدة إنجليزية وعربية شائعة، مع إمكانية تعديل المطابقة يدوياً. القيم غير الرقمية تُتجاهل ويظهر تنبيه بعددها. يدعم منسّق الأرقام القياسي والفواصل الشائعة للعملات مثل `1,234.50` و`1.234,50`. اختيار رمز العملة يغيّر الرمز الظاهر فقط ولا يحوّل القيم.

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

لتشغيل صفحة الخدمة محليًا كما تظهر للزوار:

```bash
streamlit run service_app.py
```

ولتجربة المحلل المحلي للمالك، أوقف الأمر الأول ثم شغّل:

```bash
streamlit run owner_app.py
```

ارفع `examples/demo_ads.csv` إلى محلل المالك واترك المطابقة التلقائية كما هي؛ ستظهر مؤشرات الأداء والرسوم. على Windows أنشئ البيئة الافتراضية بـ `python -m venv .venv` ثم فعّلها عبر `.venv\\Scripts\\activate`.

## الاختبارات

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

تغطي الاختبارات قراءة CSV وXLSX من الذاكرة، الحساب والتجميع، العملات، الأعمدة العربية، التواريخ، القيم غير الرقمية، والملفات الفارغة أو التالفة أو التي تتجاوز الحدود. كما تتضمن اختبار تحميل اصطناعياً لـ100 ألف صف واختبارات تكامل للمحلل المحلي والمدخل العام وصفحة الخدمة؛ وتتحقق صفحة العميل من وجود التواصل والسعر وعدم وجود رفع ملفات أو مؤشرات تحليل.

## حدود الملفات والخصوصية

صفحة الخدمة العامة `app.py`/`service_app.py` لا تستقبل ملفات أو تعرض تحليلات. أما محلل المالك `owner_app.py` فيقبل ملفات حتى 20 ميجابايت (يضبطها `.streamlit/config.toml`)، و250,000 صف، و100 عمود. يقرأ الرفع من بايتات الجلسة في الذاكرة ولا يستدعي التطبيق حفظاً إلى القرص أو إرسالاً لخدمات تحليل خارجية. على الاستضافة السحابية تنتقل بيانات الملف إلى خادم التطبيق أثناء الرفع والمعالجة، وتظل سياسات الاحتفاظ وسجلات مزود الاستضافة خارج سيطرة هذا المستودع؛ لا ترفع معلومات شخصية أو سرية قبل مراجعة سياسات الاستضافة والامتثال.

لا يتضمن المشروع تسجيل دخول أو عزل مستأجرين، ولا يرسل التقارير بالبريد، ولا يحتوي على دفع مدمج؛ طلب الخدمة المدفوعة والدفع وإرسال التقرير يجري يدويًا عبر واتساب. كما لا يحسب محلل المالك هامش الربح أو صافي ROI لغياب تكلفة البضاعة والمرتجعات والرسوم. لا تضع مفاتيح API أو بيانات عميل في المستودع.

## إعداد النشر

يظل مدخل Streamlit Cloud `app.py`، وهو الآن يشغّل صفحة الخدمة فقط. لم تتغير إعدادات الاستضافة من داخل هذا المستودع. لا تستخدم `owner_app.py` كمدخل عام لأنه يتيح رفع ملفات وتحليلها من دون مصادقة.
