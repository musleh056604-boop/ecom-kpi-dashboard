# لوحة أداء المتجر والإعلانات

تطبيق Streamlit عربي يقرأ ملف CSV أو XLSX، يساعد على مطابقة أعمدة المتجر أو الإعلانات، ثم يحسب مؤشرات الأداء ويعرض مقارنات ورسومًا تفاعلية. صُمم ليكون نقطة بداية عملية للمراجعة؛ ليس نظام فوترة أو منصة SaaS متعددة العملاء.

## ما الذي يحسبه؟

- إجمالي الإنفاق والإيراد والطلبات ضمن الفترة المختارة.
- **ROAS** = الإيراد ÷ الإنفاق الإعلاني، وليس عائداً صافياً أو ربحاً.
- **CPA** = الإنفاق ÷ الطلبات، و**CPC** = الإنفاق ÷ النقرات.
- **CTR** = النقرات ÷ مرات الظهور، و**معدل التحويل** = الطلبات ÷ النقرات.
- **AOV** = الإيراد ÷ الطلبات.
- مرشح تاريخي، مقارنة أعلى 20 فئة حسب عمود يختاره المستخدم، واتجاه الإيراد اليومي عند توفر التاريخ والإيراد.

يعرض التطبيق المؤشر على أنه «غير متاح» عندما لا تتوفر الأعمدة اللازمة أو يكون المقام صفراً. يكتشف أسماء أعمدة إنجليزية وعربية شائعة، مع إمكانية تعديل المطابقة يدوياً. القيم غير الرقمية تُتجاهل ويظهر تنبيه بعددها. يدعم منسّق الأرقام القياسي والفواصل الشائعة للعملات مثل `1,234.50` و`1.234,50`. اختيار رمز العملة يغيّر الرمز الظاهر فقط ولا يحوّل القيم.

## التشغيل في أقل من دقيقة

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

ارفع `examples/demo_ads.csv` من الصفحة الرئيسية، واترك المطابقة التلقائية كما هي. سيظهر ROAS وبقية المقاييس والرسوم. على Windows أنشئ البيئة الافتراضية بـ `python -m venv .venv` ثم فعّلها عبر `.venv\\Scripts\\activate`.

## الاختبارات

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

تغطي الاختبارات قراءة CSV وXLSX من الذاكرة، الحساب والتجميع، العملات، الأعمدة العربية، التواريخ، القيم غير الرقمية، والملفات الفارغة أو التالفة أو التي تتجاوز الحدود. كما تتضمن اختبار تحميل اصطناعياً لـ100 ألف صف واختبارات تكامل للواجهة ورفع CSV/XLSX.

## حدود الملفات والخصوصية

حدود التطبيق: 20 ميجابايت للرفع (يضبطها `.streamlit/config.toml`)، 250,000 صف، و100 عمود. يقرأ ملف الرفع من بايتات الجلسة في الذاكرة؛ لا يستدعي التطبيق حفظاً إلى القرص، ولا يستخدم تخزيناً مؤقتاً للتقارير أو إرسالاً لخدمات تحليل خارجية. تُنشأ معاينة الملف وتنزيل ملخص CSV داخل الجلسة فقط. على الاستضافة السحابية تنتقل بيانات الملف إلى خادم التطبيق أثناء الرفع والمعالجة، وتظل سياسات الاحتفاظ وسجلات مزود الاستضافة خارج سيطرة هذا المستودع؛ لا ترفع معلومات شخصية أو سرية قبل مراجعة سياسات الاستضافة والامتثال.

هذا الإصدار لا يتضمن تسجيل دخول أو عزل مستأجرين، ولا يرسل تقارير بالبريد، ولا ينفذ الدفع عبر Stripe، ولا يحسب هامش الربح أو صافي ROI لغياب تكلفة البضاعة والمرتجعات والرسوم. لا تضع مفاتيح API أو بيانات عميل في المستودع.

## إعداد النشر (لم يُنفّذ)

إذا وافق مالك المشروع لاحقاً على المحتوى، يمكن ربط مستودع GitHub بمنصة Streamlit Community Cloud واختيار `app.py` كملف الدخول. تعتمد المنصة الحزم من `requirements.txt`. هذه التعليمات لا تنشئ مستودعاً ولا تنشر التطبيق، ولا تعني موافقة على نشر بيانات أو على شروط أي منصة.
